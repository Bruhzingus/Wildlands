# Phase 11 implementation and verification

Implemented on 2026-10-19. Original Generation 1 typing is intentional: Magnemite remains Electric and Clefairy remains Normal. Arcade combat parameters and authored attack names do not claim to reproduce official stats or cartridge learnsets.

PHASE: 11 — Kanto roster completion and content balancing

What changed: All 151 species now have an explicit authored loadout in `rosterContent.ts`: attack archetype, move name, role and a bounded arcade power budget. This replaces the previous ID-modulo power calculation and primary-type-only loadouts. The existing eight attack implementations remain shared. A small signature parameter table handles multishot, chain count, piercing, area and control differences. Caterpie has a usable slowing ranged shot; Magikarp has Splash Shot rather than a nonfunctional attack. Evolution increases its power and receives a 12% attack-scale increment per stage. All 72 evolution links improve conservative single-target output at equal ranks 1 and 8; measured increases range from **6.06% to 77.23%**, before area/chain/multishot benefits. Base power spans **11–29**.

Ordinary early/mid/late encounter tables cover every nonlegendary. Articuno, Zapdos, Moltres and Mew can appear as scarce normal-faction elites after 12:00, at a **0.1% chance per eligible late-table arrival**. They reuse normal elite behavior and never trigger boss victory. Mewtwo remains the scheduled boss. All 151 IDs are reachable through actual enemy encounter definitions. Scripted faction encounters can explicitly exclude rare species.

Evolution methods are data: 52 training links, 16 named stone links and four adapted trade/bond links. Named cards grant their evolution without an external trading service or separate consumable inventory. The original level 7 / level 19 and 170-second maturity gates remain; Eevee still offers three explicit cards. The developer preview displays each requirement. Recruitment continues to exclude stage-2+ and all five legendaries. Eleven single-stage species respect the finite save-unlock policy. An absent policy preserves existing unrestricted legacy behavior; provided item policies are enforced on both offers and application, including forged or stale cards. The selected Quickened challenge centrally scales newly created enemy movement by exactly 20%, without changing HP or damage.

The developer-only asset gallery now has a six-variant comparison mode as well as its existing eight-direction mode. It shows historical types, stage, attack role, power, cadence, reach, live encounter tables and named evolution rules. Every preview continues to use the real game's sprite loader, original source timing and fallback/disposal path.

Changed files: `src/data/kanto.ts`, `src/data/attacks.ts`, `src/data/rosterContent.ts`, `src/data/encounters.ts`, `src/data/evolutions.ts`, `src/data/validateRoster.ts`, `src/game/systems/spawning.ts`, `src/game/systems/progression.ts`, `src/ui/AssetGallery.ts`, `scripts/sync-roster-reference.mjs`, `scripts/audit-content.mjs`, `tests/fixtures/kanto-reference.json`, `tests/roster.test.ts`, `tests/browser/roster.spec.ts`, this report. Root integration adds the actual save policy fields, boss-table selection and exclusion of rare encounters from scripted faction arrivals.

Why the approach is maintainable: Species remain content rather than 151 separate combat classes. Original identity/type/evolution reference data is separate from authored game balance. A locally cached independent reference includes the source URLs and SHA-256 hashes of five PokeAPI CSV tables; validation runs without networking. Historical type overrides are applied when refreshing that fixture. Evolution requirements and encounter pools have one owner. Recruitment/item policy checks protect both UI offers and the authoritative application path. The developer comparison view exercises the same assets as gameplay and releases its engine on close.

Tests run: `node --experimental-strip-types scripts/audit-content.mjs` passed: **151 IDs, 151 loadouts, 72 evolution edges, 151 spawn-reachable species and 453 readable animation states; zero issues**. This reads every local Idle/Walk/Attack PNG, validates signatures, dimensions, atlas layouts and source timing, and checks creator-credit files. `node --experimental-strip-types --test tests/roster.test.ts` passed **6/6**, covering independently sourced roster/types/parents, deliberate corruption, every explicit evolution, rarity/legendary restrictions, recruit and item policy enforcement and the optional movement challenge. Existing combat/progression/spawn/icon tests passed **37/37**, including six health-maintained 15-minute progression routes reaching four living members. `npx tsc --noEmit` passed. The root report records the complete combined regression/build results.

Browser smoke steps: The new real-WebGL content case passed **1/1** in 24.7 seconds on an isolated Vite instance. It loaded all **151 species × 6 variants = 906 actual local Attack-sheet pairs**, checked source resolution, visibility and dimensions, verified role and stone/trade descriptions, restored eight-direction mode and closed/disposed the preview with **zero page errors**. Results are in `artifacts/browser/phase11-roster-variants.json`. Reproduce normally with `npm run test:browser -- tests/browser/roster.spec.ts`; the completed isolated run used `npx playwright test --config artifacts/phase11-playwright.config.ts tests/browser/roster.spec.ts --output artifacts/browser/11-roster-isolated-results`. Its temporary server disabled HMR/watch so concurrent development could not reload the tour. An earlier shared-server attempt was interrupted by a hot-reload navigation; it was not an application assertion failure.

Known limitations: Authored moves are intentional arcade interpretations rather than a battle simulator. Automated output checks establish that evolution does not reduce equal-rank damage cadence; they do not establish equal fun, identical crowd performance or human starter win rates. The weak-starter deterministic experiment and broader balance measurements are recorded in phase 12. Rare encounters have a probability per arrival, so no run is guaranteed to see a specific legendary. Six-variant preview checks cover visual loadability; encounter eligibility still restricts legendary species and actual bosses separately.

Balance / performance impact: The complete roster now has deliberate bounded power rather than arbitrary ID variance, and evolved forms gain damage scale. Signature mechanics reuse all existing projectile/proc/VFX caps. No recruitment times, XP thresholds, maximum party size, evolution maturity, boss HP or director density budget changed. Rare species consume an existing spawn slot. The optional movement modifier applies only when its challenge is selected. The extra gallery comparison controls and diagnostics are present only under `?dev=1`.

Next recommended phase: 12 — deterministic run telemetry and measured balance experiments; implemented alongside this phase by the telemetry agent.

Regression checklist: Native capture and camera-relative movement; exact recruit gates and permanent faints; explicit Eevee choices and fresh second-evolution maturity; item policy enforcement and shared archetypes; historical original typing; boss-only victory and endless continuation; bounded enemy/projectile/drop/FX resources; asset cache/fallback and gallery disposal.
